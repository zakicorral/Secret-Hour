Before anything begins…

One simple word opens everything.


Decode the message

Sound and light speak the same language.


Not everything is solved with words

I can break, I can be clogged, I can be attacked.
I can be given, I can be kept, I can be crushed.

You already named me.
Now prove you understand me.

Type the number of letters it takes to feel me.


You reached the end too early.

Some things only reveal themselves when a day ends.

Come back at midnight.

I didn’t build this to impress you.
I built it to walk with you through a whole day.

Every puzzle was patience.
Every lock was trust.
Every wait was proof that some things are worth staying for.

If you’re reading this, it means you stayed.
And that’s all I ever wanted.

Happy New Year, my heart.
And if life ever feels complicated again,
remember — you already solved me.
